# Phonics ป.1 — สื่อการสอนภาษาอังกฤษ ป.1 แบบโต้ตอบ (Interactive Web App)

เว็บแอปพลิเคชันสอนภาษาอังกฤษระดับชั้นประถมศึกษาปีที่ 1 (ป.1) ออกแบบตามหลักสูตรและจิตวิทยาการเรียนรู้สำหรับเด็กปฐมวัย/ประถมศึกษาตอนต้น ดีไซน์กระดานแม่เหล็กสีสดใส ชัดเจน ใช้งานง่ายทั้งบนจอทีวี/โปรเจกเตอร์หน้าชั้นเรียน และบนแท็บเล็ต/สมาร์ตโฟนของนักเรียน

## 🌟 ฟีเจอร์หลักในระบบ

### 1. 🔤 A–Z โฟนิกส์ (Phonics Stage & Magnetic Alphabet Board)
- **ตารางตัวอักษร 26 ตัว**: แยกกลุ่มสีชัดเจนตามหลักภาษาศาสตร์ **สระ (A, E, I, O, U) สีแดง** และ **พยัญชนะ สีฟ้า**
- **ปุ่มฝึกออกเสียง 3 มิติ**:
  - 🔊 **ชื่อตัวอักษร**: ฝึกเรียกชื่อตัวอักษร A-Z
  - 🗣️ **เสียงโฟนิกส์**: ฝึกออกเสียงตามสัทศาสตร์ พร้อมตัวสะกดเทียบเสียงภาษาไทย (เช่น `A says /æ/ แอะ`, `B says /b/ เบอะ`)
  - 📖 **อ่านคำศัพท์**: ฟังเสียงคำศัพท์ภาษาอังกฤษสำเนียงเจ้าของภาษา
- **คลังคำศัพท์ตัวอย่าง**: 3 คำศัพท์ต่อตัวอักษร รวม 78 คำศัพท์ พร้อมภาพการ์ตูนอีโมจิ คำอ่าน และคำแปลภาษาไทย

### 2. 🃏 บัตรคำภาพ (3D Flippable Flashcards)
- พลิกบัตรคำเสมือนจริง 3 มิติ สลับดูภาพคำศัพท์และคำเฉลย/คำอ่าน/คำแปล
- **โหมดทายคำ (Quiz Mode)**: ซ่อนคำศัพท์ด้านหน้า เพื่อให้ครูกดสุ่มถามนักเรียนหน้าชั้นก่อนแตะเฉลย
- **ระบบสลับไพ่ (Shuffle)** และ **เล่นอัตโนมัติ (Auto-play)**
- เลือกเปลี่ยนชุดคำศัพท์ได้ทั้งแบบ A–Z และแบบคำศัพท์ผสมเสียงตามสระ

### 3. 🧩 โรงงานผสมคำ CVC (CVC Word Blender)
- ครอบคลุมสระเสียงสั้น 5 หมวด: **สระ a, e, i, o, u** รวม 40 คำศัพท์
- **แยกเสียงตัวอักษร (Phonics Segmenting)**: แตะทีละตัวอักษรเพื่อฟังเสียงโฟนิกส์เดี่ยว
- **แอนิเมชันผสมเสียง (Sound Blending Animation)**: กดปุ่ม **“ผสมเสียง! (Blend)”** เพื่อฟังเสียงทีละตัว แล้วตัวอักษรจะเลื่อนมารวมร่างกันเป็นคำศัพท์พร้อมเอฟเฟกต์เฉลยภาพ

### 4. 🎛️ เครื่องมือสนับสนุนครูผู้สอน
- **ปรับสปีดเสียงอ่าน**: สลับเสียงปกติ (1.0x) และเสียงอ่านช้าสำหรับเด็กเล็ก (0.6x)
- **โหมดเต็มจอ (Fullscreen)**: ขยายเต็มจอสำหรับจอสัมผัสหรือสมาร์ตบอร์ด
- **คีย์ลัดคีย์บอร์ด**:
  - `◀` / `▶` : เปลี่ยนตัวอักษร / บัตรคำ
  - `Spacebar` : เล่นเสียงโฟนิกส์ / คำศัพท์
  - `Enter` : พลิกบัตรคำ

## 🚀 เทคโนโลยีที่ใช้
- **HTML5 / CSS3 (Modern Vanilla Web)**: ไม่มี dependencies เพิ่มเติม โหลดเร็ว ประหยัดหน่วยความจำ
- **Web Speech API**: สังเคราะห์เสียงอ่านภาษาอังกฤษสำเนียงธรรมชาติ
- **Web Audio API**: สังเคราะห์เสียงเอฟเฟกต์การกดปุ่ม (Popping Sound) และเสียงเฉลย (Chime)
